Atributos das Tags de Mídia

Tanto a tag <audio> quanto a <video> compartilham a maioria dos atributos, já que ambas são tags de mídia. No entanto, existem alguns atributos que são exclusivos para cada tipo de mídia.

Abaixo, apresentamos uma referência completa de todos os atributos disponíveis, o que cada um faz, e exemplos de uso prático.

Atributos Comuns Áudio e Vídeo

Estes atributos podem ser utilizados tanto na tag <audio> quanto na tag <video>.

Atributo Valor O que faz?
controls (booleano) Exibe os controles de reprodução nativos (play, pause, volume, progresso).
autoplay (booleano) Inicia a reprodução automaticamente ao carregar a página.
loop (booleano) Repete a reprodução da mídia em loop infinito.
muted (booleano) Inicia a mídia com o áudio silenciado (sem som).
preload none / metadata / auto Define se e como a mídia deve ser pré-carregada pelo navegador.
src URL Especifica o caminho direto do arquivo de mídia.
volume 0.0 a 1.0 Define o nível do volume da mídia (controlado via JavaScript).
currentTime segundos Define ou retorna a posição de tempo atual da reprodução (via JS).
duration (somente leitura) Retorna a duração total da mídia em segundos (via JS).
paused (somente leitura) Retorna true se a mídia estiver pausada (via JS).
ended (somente leitura) Retorna true se a reprodução da mídia foi concluída (via JS).

Atributos Exclusivos Apenas Vídeo

Estes atributos são aplicáveis exclusivamente à tag <video>.

Atributo Valor O que faz?
width pixels Define a largura física do player de vídeo.
height pixels Define a altura física do player de vídeo.
poster URL Exibe uma imagem de capa antes de o vídeo iniciar a reprodução.
playsinline (booleano) Faz o vídeo tocar inline dentro da página no iOS, em vez de abrir em tela cheia nativa.
controlslist nodownload / nofullscreen / noremoteplayback Oculta opções ou controles específicos do painel padrão do navegador.

Explicação Detalhada dos Atributos

Vamos analisar como funcionam na prática os atributos mais importantes.

1. controls

Para que serve: Exibe a barra de controles com botões de play, pause, volume, linha do tempo e tela cheia (para vídeos).

Exemplo
<audio controls>
    <source src="musica.mp3" type="audio/mpeg">
</audio>

Sem ele: A mídia existirá na página, mas o usuário não terá uma interface visual direta para controlá-la.

2. autoplay

Para que serve: Faz com que o arquivo de mídia comece a tocar imediatamente após o carregamento da página.

Exemplo
<video autoplay>
    <source src="video.mp4" type="video/mp4">
</video>
⚠️
Atenção: A maioria dos navegadores modernos bloqueia reprodução automática com som para evitar incomodar o usuário. Combine-o com muted para funcionar.

3. loop

Para que serve: Faz com que a reprodução reinicie automaticamente ao chegar ao fim, criando um ciclo contínuo.

Exemplo
<audio loop>
    <source src="musica.mp3" type="audio/mpeg">
</audio>

Quando usar: Excelente para efeitos sonoros repetitivos ou trilhas sonoras de fundo (background music).

4. muted

Para que serve: Inicializa a mídia com o volume em zero (totalmente silenciada).

Exemplo
<video muted autoplay>
    <source src="video.mp4" type="video/mp4">
</video>

Quando usar: Vídeos de fundo decorativos ou para satisfazer os requisitos dos navegadores sobre autoplay.

5. preload

Para que serve: Indica ao navegador qual estratégia de carregamento deve ser utilizada antes de o usuário clicar em "play".

Valor Significado
none Não carrega nenhum dado preventivamente, economizando largura de banda.
metadata Carrega apenas as informações básicas (duração, dimensões do vídeo, etc.).
auto Tenta carregar o arquivo de mídia completo em segundo plano imediatamente.
Exemplo
<video preload="metadata">
    <source src="video.mp4" type="video/mp4">
</video>

Dica: Use metadata ou none para páginas contendo múltiplos players de mídia para melhorar o desempenho de carregamento.

6. poster (somente vídeo)

Para que serve: Define uma imagem de capa personalizada que fica visível no player enquanto o vídeo não começou a tocar.

Exemplo
<video poster="capa.jpg" controls>
    <source src="video.mp4" type="video/mp4">
</video>

Quando usar: Praticamente sempre. Agrega valor estético e fornece um contexto visual imediato do que o vídeo trata.

7. width e height (somente vídeo)

Para que serve: Define a proporção física e dimensões em pixels da área de renderização do player.

Exemplo
<video width="640" height="360" controls>
    <source src="video.mp4" type="video/mp4">
</video>

Dica de CSS: Para criar um player responsivo, defina max-width: 100% e height: auto em seu arquivo de estilos.

8. src vs <source>

O atributo src é ideal quando você possui apenas um formato e deseja simplicidade. A tag filha <source> permite oferecer múltiplos formatos, permitindo ao navegador escolher o primeiro compatível.

Exemplo simplificado com src:
<audio src="musica.mp3" controls></audio>
Exemplo recomendado com múltiplos <source>:
<video controls>
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    <source src="video.ogv" type="video/ogg">
</video>

Recomendação: Utilize múltiplos <source> para garantir compatibilidade com todos os navegadores.

Exemplos Combinados completos

Estes códigos mostram a combinação avançada de múltiplos atributos em uso simultâneo.

Vídeo Completo

<video 
    width="640" 
    height="360" 
    poster="capa.jpg" 
    controls 
    autoplay 
    muted 
    loop 
    preload="metadata"
    playsinline>
    
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    Seu navegador não suporta vídeos HTML5.
</video>

Áudio Completo

<audio controls loop preload="none">
    <source src="musica.mp3" type="audio/mpeg">
    <source src="musica.ogg" type="audio/ogg">
    Seu navegador não suporta áudio HTML5.
</audio>

♿ Dicas de Acessibilidade

  • Descrições de mídia: Sempre utilize aria-label ou title para descrever brevemente a mídia para leitores de tela.
  • Legendas: Sempre que possível, adicione legendas aos vídeos usando o elemento <track>.
  • Navegação por Teclado: Garanta que os controles de reprodução padrão sejam acessíveis e operáveis via teclado.

Exemplo de Legendas Integradas:

<video controls>
    <source src="video.mp4" type="video/mp4">
    <track src="legendas.vtt" kind="subtitles" srclang="pt" label="Português">
</video>

Dominar os atributos das tags <audio> e <video> é essencial para criar páginas ricas, acessíveis e compatíveis com diferentes navegadores. Experimente combinar atributos, testar em navegadores diferentes e sempre priorizar a experiência do usuário!
